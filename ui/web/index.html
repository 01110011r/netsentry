Prototype notes. This is a client-side simulation built for demonstration purposes: device states, traffic values and alerts are generated in the browser rather than read from real sensors. The intended architecture pairs lightweight agents on IoT endpoints (reporting packet rate, connection count and destination entropy) with a central gateway that scores each device against a rolling baseline; readings above the sensitivity threshold raise an alert and can trigger automatic quarantine. The "Simulate intrusion" control stands in for that scoring pipeline so the detection and response flow can be reviewed without live hardware.
